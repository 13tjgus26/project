# **프로젝트 이름: 트렌드 기반 동네 핫플 밀집도 분석기**
## **무엇을 하는 프로그램인가요?**
위치정보시스템학 전공 지식을 프로그래밍 기초 문법과 결합하여 만든 텍스트 기반 지도 시각화 프로그램입니다. 저는 핫플레이스 위치 데이터를 받아서 격자 모양의 텍스트 지도로 시각화하고, 특정 구역의 밀집도를 분석하는 '핫플 분포 시뮬레이터'를 개발했습니다.
## **개발 동기 및 목적**
현재 인스타그램 등에서 유행하는 카페나 맛집 정보는 많이 소개되고 있지만, 막상 그 동네에 갔을 때 이 카페랑 맛집이 서로 얼마나 멀리 있는지, 어느 골목에 핫플이 몰려 있는지 등 한눈에 파악하기가 어렵습니다. 저는 위치정보시스템학 전공자로서 지도의 원리를 이용해, 내가 가고 싶은 장소들을 격자 좌표 위에 직접 표시해보고 싶었습니다. 제가 배운 파이썬의 기본 기능(리스트, 반복문)만으로 우리 동네의 핫플 지도를 제 손으로 직접 그려보는 경험을 하기 위해 이 프로젝트를 기획하였습니다. 단순히 목록을 나열하는 것보다 지도로 시각화하면 어디가 제일 번화한 곳인지 더 쉽게 이해할 수 있기 때문입니다.

## **사용된 Python 개념**

- **변수 및 데이터 타입:** 지도 크기, 장소 이름, 메뉴 선택 번호 등을 알맞은 데이터 타입(정수형, 문자열)으로 저장하고 관리합니다.
- **2차원 리스트 (Nested List):** 행(Row)과 열(Column) 구조를 가진 2차원 공간 레이아웃을 구현하여 바둑판 모양의 가상 격자 지도를 시각화합니다.
- **딕셔너리 (`dict`):** 개별 핫플레이스의 상세 정보(이름, 카테고리, X 좌표, Y 좌표)를 하나의 독립된 객체처럼 Key-Value 쌍으로 묶어 구조화합니다.
- **리스트 (`list`):** 여러 개의 핫플 딕셔너리 데이터를 동적으로 추가하고 유지하는 데이터베이스 역할을 수행합니다.
- **반복문 (`for`, `while`):** 사용자가 종료(6번)를 선택하기 전까지 메뉴를 무한히 실행하며, 지도를 화면에 한 줄씩 렌더링하거나 전체 핫플 리스트를 순회하며 조건에 맞는 데이터를 탐색할 때 활용합니다.
- **조건문 (`if-elif-else`):** 사용자가 선택한 메뉴 번호에 따라 알맞은 함수를 분기 실행하고, 카테고리(카페/식당)에 따라 지도에 다른 기호(`C`/`R`)를 매칭합니다.
- **함수 모듈화:** 기능별로 코드를 세부적으로 쪼개어 총 8개의 함수 체계(`create_map`, `is_valid_coordinate`, `add_place`, `display_map`, `analyze_density`, `search_place`, `save_data`, `load_data`, `clear_map_data`)를 구축함으로써 코드의 재사용성과 가독성을 극대화했습니다.
- **예외 처리 (`try-except`):** 사용자가 숫자가 아닌 문자열을 입력하여 발생하는 시스템 오류(ValueError)를 안전하게 예방하고 프로그램의 연속적인 구동을 보장합니다.
- **파일 입출력 (`open`, `write`, `read`):** 외부 텍스트 파일(`hotplaces.txt`)과의 연동을 통해 프로그램이 종료되더라도 데이터를 영구적으로 보존하고 자동 로드하는 영속성 데이터를 구현했습니다.

## **한계와 다음 단계**

- **한계:** 
   1. **데이터 중복 등록 문제:** 현재 프로그램은 동일한 좌표에 새로운 핫플을 등록하거나, 같은 이름의 장소를 여러 번 입력해도 이를 중복으로 걸러내지 못하고 그대로 덮어쓰거나 누적하는 한계가 있습니다.
  2. **지도의 고정된 크기:** 프로그램 시작 시 지도의 크기를 한 번 정하면 실행 도중에는 지도 크기를 바꿀 수 없어서, 더 넓은 지역의 데이터를 추가하고 싶을 때 프로그램을 재시작해야 하는 불편함이 있습니다.
  3. **시각적 가독성:** 텍스트 기반 기호(`C`, `R`)로만 지도를 표시하다 보니, 등록된 데이터가 수십 개 이상으로 많아지면 화면이 한눈에 들어오지 않고 복잡해 보입니다.

  3. **실제 인터넷 지도 연동:** 파이썬의 지도 시각화 도구를 공부해서, 터미널 창의 글자 지도를 넘어 우리가 스마트폰으로 보는 실제 웹 지도 위에 마커를 찍고, 맛집이 몰려 있는 구역은 불꽃 모양 기호(`🔥`)나 붉은색으로 번쩍이게 만드는 밀집 구역 강조 기능을 구현해보고 싶습니다.
